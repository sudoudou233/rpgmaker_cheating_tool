# RPG Maker 存档修改器 (rpgmaker_cheating_tool)

mtool每次打开都要更新，于是随手让ai做了这么个玩意，可以修改rpgmaker游戏物品、角色等级属性、金币等，这个项目本身是ai做的，本人不会做后续维护更新。

---

## 功能

- 自动识别 RPG Maker 引擎（MV / MZ / VX Ace / VX / XP）
- 修改金币、步数
- 修改道具 / 武器 / 防具数量（可添加背包里没有的物品）
- 修改角色等级、经验、HP、MP、TP、8 项属性加成、技能
- 修改游戏开关（Switch）与变量（Variable）
- 保存前自动生成 `.bak` 备份

## 支持的引擎与存档格式

| 引擎 | 识别特征 | 存档文件 | 说明 |
|---|---|---|---|
| RPG Maker MV | `www/js/rpg_core.js` | `www/save/file*.rpgsave` | LZString 压缩 JSON |
| RPG Maker MZ | `js/rmmz_core.js` | `save/file*.rmmzsave` | zlib 压缩 JSON |
| RPG Maker VX Ace | `Data/*.rvdata2` | `Save*.rvdata2` | 兼容 MTool 等修改版运行时 |
| RPG Maker VX | `Data/*.rvdata` | `Save*.rvdata` | 标准 Ruby Marshal |
| RPG Maker XP | `Data/*.rxdata` | `Save*.rxdata` | 标准 Ruby Marshal |
| RPG Maker 2000/2003 | `RPG_RT.ini` | — | 仅识别，暂不支持 |

> 修改存档时只改动你指定的数值，其余数据**字节级原样保留**，保证游戏能正常读取。

## 环境要求

- Windows
- Python 3.8+（无需额外安装任何第三方库）

## 使用方法

### 方式一：双击启动

双击 `启动修改器.bat` 即可打开图形界面。

### 方式二：命令行

```
python main.py
```

### 操作步骤

1. **选择游戏目录**：点击「浏览」选择游戏根目录（包含 `www` 或 `Data` 文件夹的那一层），或直接在输入框粘贴路径，然后点「读取游戏数据」。
   - 工具会自动识别引擎并列出该游戏的全部道具 / 武器 / 防具 / 角色数据。
2. **选择存档**：从下拉框选择一个存档文件，点「加载」。
   - 如果提示"当前没有存档文件"，说明该游戏还没保存过，先进游戏随便存一次档再回来。
3. **修改数据**：
   - **队伍/金币**：直接改金币、步数数值，点「应用金币/步数」。
   - **道具/武器/防具**：列表显示所有物品及当前数量。在 ID 框输入物品编号、数量框输入目标数量，点「设置数量」；也可以点「数量+1 / 数量+10」快捷增减，「清零」一键清空。
   - **角色**：选中角色后，可修改等级、经验、HP、MP、TP，以及 8 项属性加成（索引 0-7 对应 最大HP/最大MP/攻击/防御/魔攻/魔防/速度/幸运）；下方可整体替换技能列表（技能 ID 用逗号分隔）。
   - **开关/变量**：输入 ID 和值后点「设置」。
4. **保存**：点「保存存档」，会先在原存档旁生成 `.bak` 备份，然后写入修改后的存档。

## 常见问题

**Q：修改后游戏里没生效？**
A：确认保存时选择的是游戏实际读取的存档文件；部分游戏有多套存档（如自动存档），需要全部修改或修改对应档位。

**Q：某些游戏报"无法识别引擎"？**
A：确认选择的是游戏根目录；部分汉化/破解版游戏结构特殊，可尝试选择内层带 `www` 或 `Data` 的目录。

**Q：修改后的存档游戏读不了？**
A：先用备份 `.bak` 恢复，再重新修改。修改时请保持数量为合理整数（不要超过程序能表示的范围）。

```
├── main.py        # 图形界面入口
├── engines.py     # 引擎自动识别

├── mvdata.py      # MV / MZ 引擎存档读写
├── rmarshal.py    # Ruby Marshal 解析/写入（含多种变体）
├── lzstring.py    # LZString 压缩算法 (MV 存档)
└── test_*.py      # 自动化测试
```
